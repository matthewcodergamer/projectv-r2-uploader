# Project V R2 Uploader

Mobile-first multipart uploader for the Project V source archive.

- Cloudflare R2 multipart upload
- 32 MiB parts with resumable sessions
- Safe pause/resume across Wi-Fi or mobile-data changes
- Two parallel upload streams
- Retry handling and final size verification
- Project V white V + green upload badge used for the page, favicon, and Home Screen/PWA icon
- Varied original console-style controller UI chimes for tap feedback
